## 目标

每日看板统一临时输入 → 本地规则或已配置AI识别 → 可修改预览 → 确认事务入库；无需AI即可使用，新输入不保存长期文档，旧文档只读保留。

## 核心合同

使用 `- 任务名, @地点, 时间, (提醒1,提醒2);`，仅标题必填。时间点为待办DDL，时间段用>。日期简写按当前年/今天，日期时间兼容空格/+。提醒省略默认5和0，()关闭；无时间待办省略相对提醒不安排，显式相对需补DDL或关闭，仅绝对无需DDL。

分号结束条目，无分号回车进入子级，有分号保持同级；#备注跟在结束分号后直到行尾。标题/地点用首尾半角双引号保护分隔符，内部双引号保留。无日期23:00>01:00提示补结束日期，不自动次日。

循环用每天/每N天/每周/每N周/每月/每年加方括号；多时段共用外部字段。范围可选自日期至日期或截至日期，缺省从今天持续生成，展示窗口不作截止。课程关联支持本次、某时段后续及整课修改。

## 循环绝对提醒

决定来源：本轮按最后单一推荐方案后用户继续执行，决策014不伪写数字选项回复。每个不同绝对时刻只归属整门课所有时段中最近Start>=absolute实例，相等本次，并列输入顺序；相对每次，过去不补响。窗口外提前物化，有限范围无目标整批拒绝；补齐、改单次、取消或共同字段修改不复制或自动重新分配。
