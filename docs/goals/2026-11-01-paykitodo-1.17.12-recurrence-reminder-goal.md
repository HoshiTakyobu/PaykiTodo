# Windows 1.17.12 循环单次提醒修复目标

来源：用户持续要求继续原七项目标。检查尚待确认的循环绝对提醒时，发现既有Windows实例补齐和系列编辑会复制单次提醒；本轮在原任务范围内先修复这个不依赖语法选择的缺陷。

- 保留各实例自己的绝对提醒，禁止补齐时复制到后续事项；相对提前规则继续按每次安排计算。
- 系列共同字段和改期编辑保持实例提醒，单纯改名不会关闭另一实例的提醒；显式关闭仍按所选范围生效。
- 用独立桌面、专用资料及实际新成品验收，不操作真实账号、手机、模拟器或用户普通数据。
- Windows升为1.17.12.0；Android保持1.17.11/403、Room34，无新APK。
- 构建并校验MSI与完整便携目录，同步当前文档；保留原始失败、恢复副本及已清理的阶段历史。
- 新规划文本的循环绝对时刻仍等待用户选择，不把本轮保护当作一次归属或另建单次事项的确认。整轮目标与最终push保持未完成。

实际结果与边界见[验收](../current/VALIDATION_1.17.12.md)。本文件随功能提交之后单独归档，不替代原始未跟踪规划Prompt或创建新的自动目标。
