# PaykiTodo 1.17.16：界面布局与日历密度改进

## 基线与边界

- 从 1.17.15 / Android versionCode 407、Windows 1.17.15.0 增量实施；本轮目标版本 1.17.16 / 408。
- 原有未跟踪规划文档不属于本轮；用户数据、凭据、数据库、历史成品不修改。验证使用隔离资料。
- 保留业务能力、事务编辑、循环作用域、提醒、日历归属、共享权限、备份与同步合同。只做本轮明确的界面改进；不发布、不推送、不部署。

## 完整目标

1. 每日看板：移除“按时间”与条目外的“待办／日程”标签；待办与日程使用同一紧凑条目几何、同高基线、相同左侧色条位置。待办取主分组色、日程取自身色；父任务信息仍可见，完成操作保留。
2. 新增／编辑事项：日程时区不再作为编辑行，统一从设置管理；新建跟随设置，旧事项保留其已存时区。标题采用“添加主题”灰色占位与融入式输入。时间行采用时钟、开始日期、开始时间、分隔线、结束时间、结束日期。保留全天、重复、地点、备注、提前提醒、所属日历、颜色和现有其他能力；重复与颜色常显，不藏在高级折叠中。
3. 颜色：持久化 12 个 RGB 值并使用两行六列色块，不显示色名，选中块用白色勾。分组和日历选择均有左侧圆角方形色标；日程标签为“日程颜色”，待办使用对应文案。旧自定义颜色无损保留，不强制迁移数据。
4. 详情：不重复窗口标题；按内容高度布局，缩减空白，主要动作与次要／危险动作区分，保留编辑、复制、完成／恢复、签到、取消、删除和关闭。
5. AI 报告：列表本身渲染 Markdown 预览，不能露出原始标记；每份报告的阅读入口位于右侧。保留全文阅读、来源、到期删除和原文。
6. 设置：移除内容区内第二套纵向抽屉，改为紧凑、清晰的分类导航。改善默认正文排版，保留用户主动选择的字体、字号及固定品牌／导航艺术字。
7. 桌面日历：日期导航与日历、视图、设置、创建按钮尽量同一行，宽度变化时紧凑适配而不裁切；统一小号矢量折线箭头，禁止拉成长 V 或使用字符代替。
8. 桌面列表：七天的左侧日期轨与右侧日程对齐，空日期有一致的行高与弱化占位；保留所选周、周起始设置与翻周。
9. 手机日历：重做顶部“日历 · 数量”入口为清晰紧凑的带图标日历管理入口，保留可见日历数量与设置功能；相关编辑／颜色及看板显示保持一致。
10. 桌面周视图始终七天，取消窄窗口自动变为三天。按标准一小时日程格的高度与 1:1.5 宽高关系推导最小宽度，计入时间轴、边距和导航；窄屏隐藏辅助月历而非工作周，字体放大后重新计算。
11. 核查 Windows 图标底部透明度及像素；只在图标本身确有暗边时修正资源，区别 Windows 文字阴影与图标像素。
