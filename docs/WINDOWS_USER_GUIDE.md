# PaykiTodo Windows 使用说明

适用于 Windows 1.17.15.0。应用内 HTML 阅读器使用本地资源，断网可阅读，目录可展开、收起。

## 开始使用

PaykiTodo 把待办、日程、提醒和倒数日放在同一个工作区。Windows 客户端保存自己的本地副本，使用同一账号可与手机同步。

首次打开时选择登录服务器，再注册或登录账号。服务器由服务提供者提供；账号属于所选服务器。不要把“连接手机”中的局域网地址填作账号服务器。

登录成功后，即使网络暂时不可用，也可以继续查看和编辑已有本地数据。同步会在恢复连接后继续。明确退出账号会锁定工作区，但保留本地数据。

打开“设置 → 常规 → 打开使用说明”，或在主窗口按 F1，可离线阅读这份帮助。

## 每日看板与待办

每日看板使用一张“今日安排”卡混合展示待办与日程，并保留日期、明天预览和近期目标。全天日程先列，其余事项按日程开始时间、待办自己的 DDL 排序，同时刻日程先于待办；无 DDL 待办放在“未定时间”。仍需处理的逾期待办带原日期，明天也展示有 DDL 的待办。

例如 13:30 会前准备 → 14:00–17:00 小组会 → 15:00 提交记录 → 17:30 整理。提交记录的 DDL 始终是 15:00，不自动变成日程开始时间。清单子项按自身时间显示并保留来源，“待办”页继续按树结构管理。

需要完成但没有固定时段的事情适合建成待办；明确占用一个时间段的安排适合建成日程。

点击“新增待办”，填写标题、可选截止时间、提醒和分组，再点击“完成”。按取消或关闭编辑窗口不会保存草稿。点击待办前的圆形勾选框可标记完成；历史记录中的事项可以恢复。

每日看板的“输入规划”可一次输入多条待办和日程。父子事项保留层级，每条任务都是数据库记录，支持完成、历史查看和备份。

## 日历与日程

日历支持日、周、月和列表视图。宽度不足或选择较大字号时，周视图会减少同时显示的天数。点击“今天”返回当前日期，用左右箭头切换当前视图范围。

列表展示所选周的七天，上一周、下一周固定移动七天，周起始日和显示时区决定范围。跨周事项显示本周延续的日期；恰好在周开始时结束的事项不进入本周。过去周仍可查询，空日和空周有相应提示。

在时间网格空白处单击可预览一个时段，再次点击蓝色草稿打开编辑器。也可以点击“创建日程”。填写标题、日期和起止时间、地点等，确认后保存。点击已存在的日程查看完整内容。

拖动日程可以改期，拖动下边缘可以调整结束时间；按 Esc 取消拖动。修改循环事项时，请留意“当前、当前及之后、全部”的范围选择。取消编辑不会改变整个系列。

日历与任务分组是两种不同的分类。隐藏一个日历只影响显示，不会关闭其中的提醒。日历设置中可以调整默认时长、提醒、周起始日、颜色样式和显示时区。

待办与日程选色显示真实色块，自定义旧颜色也会保留。时间轴日程标题按可用空间最多三行，其后显示时间和非空地点；极短时段使用紧凑指示，悬浮或点击详情可看完整内容。“日历设置 → 日程颜色”提供现代浅底彩字和经典纯色底的同一日程预览，浅色自动使用可读文字。预览属于草稿，完成后才保存，取消保留原选择。

在“日历 → 共享与邀请”查看共享日历与待处理邀请。创建共享日历后，从“成员”填写对方账号和只读/可编辑权限，发送邀请；对方接受后才能访问。在日程编辑中选择共享日历并管理参与人，受邀成员可从日程详情回应。共享内容由所选服务器按权限保存，个人日历继续使用账号的加密快照；服务器需支持共享接口。隐藏日历只改变显示，撤销成员权限才改变访问。

## 提醒、历史与倒数日

有截止时间的待办可以在截止前或截止时提醒；日程通常相对开始时间提醒。修改提醒后，先确认时间和开关，再完成编辑。新录入的历史时间不会补响已经过去的提醒。

单次绝对提醒保存在所属事项中，循环补齐及系列修改不会将它复制给其他实例。相对提前提醒仍按每次安排计算；显式关闭系列提醒会关闭相应范围的提醒。

桌面提醒需要程序保持运行；关机、休眠或退出程序时无法按时弹出。手机的通知、锁屏权限与电池管理由 Android 单独控制。两端使用同一账号，并不意味着电脑退出后仍能代替手机提醒。

已完成或取消的事项进入历史，清理显示不会自动删除你的所有日程和待办。倒数日用于关注目标日期，完成后可以选择保留纪念。常规设置中的历史倒数日天数只影响展示。

## 规划输入与 AI 报告

从每日看板点击“输入规划”，写入文本，点击识别，在预览直接修改后确认导入。输入、识别和取消都不会创建事项；确认后创建正式待办或日程，不保存新的规划文档。旧文档可从看板的“旧规划原文”只读查看，仍保留在备份中。

```text
- 整理书桌;
- 买水果, @超市, 16:30;
- 阅读, 20:00>20:30, (); #先读第二章
- 高等数学, @教学楼201, 每周[周一 08:00>09:40, 周三 14:00>15:40], (10,0), 自2026-11-01至2027-01-15;
```

标题必填，地点、时间和提醒可省略。字段用半角逗号分隔，条目用半角分号结束；地点以 @ 开始，单时间点为待办DDL，起止用 > 表示日程。完整时间写成 `2026-11-01 14:00`，可省略年份或日期；无日期按今天，日期与时间可用空格或加号。跨午夜需要明确结束日期，`23:00>01:00`会提示补齐。

省略提醒默认提前5分钟和到点提醒，`() `明确关闭。括号内非负整数表示提前分钟，也可写绝对时刻并混合使用，例如 `(5,0,11-02+12:00)`。没有DDL的待办不安排默认相对提醒；没有DDL却显式写提前分钟时会提示补时间或关闭。过去时刻不会补响。

备注放在结束分号后，以 # 开始直到行尾。标题或地点含逗号、分号时，用半角双引号包住字段首尾，内部双引号保留。无分号的上一行按Enter进入一级子事项，有分号保持本级；Shift+Tab或“减少缩进”回上一级。取消选中父事项时，请同时调整子事项归属或选中父事项。

循环日程支持 `每天[...]`、`每2天[...]`、`每周[...]`、`每2周[...]`、`每月[15日 09:00>10:00]`、`每年[11-01 09:00>10:00]`。一个方括号中的多个时段属于同一门课，共用标题、地点和提醒。范围可写 `自2026-11-01至2027-01-15` 或 `截至2027-01-15`；省略范围从今天开始持续重复，近期实例会继续生成。月末和闰日按实际月份末日处理。课程支持只修改本次、某个时段的后续，或统一修改整门课的共同字段，其他时段时钟不会被覆盖。

普通待办、日程编辑器的循环截止日期留空表示一直重复；临时规划省略循环范围也持续重复。手机普通待办编辑器预填 DDL 后 90 天，手机日程区分“永不截止”与“指定日期”；旧批量入口的截止默认值只适用于对应入口。

循环课程中的每个绝对时刻只提醒一次，归属整门课全部时段中开始时间不早于该时刻的最近一次课程。恰好等于开始时间时归属本次；有多个时段同时最早开始时，按方括号内的输入顺序选择一个。相对提前分钟仍对每次课程生效，重复的绝对时刻去重，已过去的时刻保留但不补响。

```text
- 高等数学, @教学楼201, 每周[周一 08:00>09:40, 周三 14:00>15:40], (10,0,2030-01-08+12:00), 自2030-01-07至2030-01-11;
```

上例中2030-01-08是周二，12:00的绝对提醒只属于周三2030-01-09 14:00开始的课程，不会在每个时段或以后每周重复。10和0分钟仍在每次课程提前及开始时提醒。目标即使在近期预览窗口之外，也会按真实循环范围找到；如果改为2030-01-12+12:00，已超过这里的最后一次课程，将提示范围内没有可归属实例，保留输入供修改，不会自动创建额外待办或偷偷丢掉提醒。

本地识别无需 AI API。需要使用 AI 时，在“设置 → AI 与规划 → AI 服务配置”添加兼容的服务地址、密钥和模型，先测试连接，再在输入页勾选“使用已配置的AI识别”。AI 输出会重新通过本地语法校验；失败保留本地候选，识别结果同样需要你确认。

AI 报告根据相关待办和日程生成日报或周报；周报按周一至周日。两端使用同一套提示规则，区分此前、本期和接下来，结合周期前后各七天的安排、循环系列和签到记录。日程安排与签到不会被当作实际完成；数据少时不推测投入或病情。

日报（含手机本地模板）从生成时刻起保留 168 小时，到期从列表和数据副本中移除，旧备份或其他设备也不能把过期日报重新恢复。程序退出或系统延后后台运行时，下次打开执行清理。既有备份文件保持原样。周报沿用手机配置的保留期限，选择“永久”也不延长日报。

AI 请求会把报告周期及相邻范围的事项数据发送到你配置的服务；每段最多列出 60 条并标明总数。服务费用和可用性由服务提供者决定，密钥不包含在正常迁移包中。

点击“阅读报告”打开离线 Markdown 阅读器，支持标题、强调、引用、嵌套列表、只读任务项、代码、链接与表格。详情保留报告来源和周期；表格和代码在自身区域横向滚动，“复制原文”复制原始 Markdown，“删除报告”经确认删除当前单份报告。阅读不修改报告，不自动加载远程图片，不执行报告内 HTML；合法网页链接由点击后打开。旧报告无需重新生成；报告过期、账号变化或原文更新时撤下旧正文。

## 字体、字号与主题

打开“设置 → 常规 → 选择字体”，可以输入本机字体的中文或英文名称，也可以从列表选择。下拉列表优先显示中文名称；尚未安装的字体不能直接选用。

正文字号可在 12—22 DIP 之间调整，默认 14 DIP，实际像素随 Windows 显示缩放变化。滑块旁会显示数值，下方同时预览中英文、数字、任务时间和输入框。只有点击“完成”才应用并保存；取消保留原来的字体和字号。

字号按界面层级调整标题、正文和输入框。品牌、导航图形以及看板问候字样保持原设计。设置会随数据副本保留；另一台电脑没有安装所选字体时使用系统推荐字体。

主题可选择浅色或深色。窄窗口里的设置操作会排到说明下方，内容较多时可向下滚动。

## 备份与同步

“设置 → 数据与备份 → 导出备份”生成 .paykibak 迁移包，可供 Windows 与 Android 导入。重要修改前可以主动导出一份副本。备份文件包含个人事项，应保存在你信任的位置。

从迁移包恢复会替换当前本机数据，程序会先保留操作前副本。请阅读确认信息并核对文件来源。遇到同步分歧时，先检查云端与本机记录，再决定恢复方向；不要反复尝试覆盖。

程序会自动同步，设置中也提供“立即同步”。独立事项的改动可以自动合并；同一事项上的竞争修改、删除与编辑等真正冲突仍需明确处理。

“连接手机”是兼容的浏览器入口：手机开启“连接电脑”后，在浏览器访问手机显示的地址，直接操作手机数据。它与独立 Windows 客户端的账号同步互不替代。

## 安装、更新与快捷键

安装版使用 Windows x64 MSI，便携版必须保留解压后的完整目录，不能只复制 PaykiTodo.exe。卸载程序不会自动删除当前 Windows 用户的数据目录。

点主窗口 X、Alt+F4 或系统菜单关闭，隐藏到通知区域，后台提醒、同步和更新准备继续；普通最小化仍进入任务栏。双击托盘或“打开 PaykiTodo”恢复同一窗口与页面；图标可能在通知区域折叠菜单中。托盘“退出”才真正停止程序。编辑窗口关闭仍为取消，不保存草稿。

在“设置 → 关于”检查更新、查看发布说明，或手动下载并准备更新。客户端每12小时最多自动检查一次稳定版本；发布方可逐步扩大灰度范围，本机的分组保持稳定。手动选择下载可提前参与，取消下载保持当前版本。

Windows 在后台准备独立的新版本目录。支持增量的发布只下载变化文件，基线不匹配或增量校验失败会改用完整包。全部文件通过签名清单校验后，托盘“退出”并重新启动才切换，单纯关闭到托盘不会重启；新版本未正常显示主窗口时回退到可用旧版。安装版快捷方式和便携目录中的 PaykiTodo.Launcher.exe 都走这条链路，直接打开 PaykiTodo.exe 也会转交启动器。不要只搬走单个 EXE。

更新缓存与账号、事项和配置分开保存。MSI 修复仍修复安装的基础版本，不覆盖用户数据；卸载移除程序和快捷方式，保留用户数据及更新缓存。重新安装后可继续使用经过校验的新版本；更高的 MSI 基础版本优先于旧缓存。旧发布未提供签名更新资产时，请打开发布页面下载 MSI，托盘退出旧程序后安装。Android 的 Debug 与 Release 签名不同，不能直接相互覆盖安装。

F1：打开使用说明。
Ctrl+F：定位搜索框，输入标题、地点或备注后按 Enter 查看结果。
Ctrl+N：新增事项；在日历页新建日程，在其他业务页新建待办。
Esc：取消日历拖动或关闭支持取消的窗口。

如遇问题，请记录版本、操作步骤和看到的提示。不要在公开 issue 中粘贴服务密钥、私有服务器地址或包含个人记录的备份。
