# PaykiTodo 版本 1.15.0 开发目标

## 项目背景
PaykiTodo 是一个 Android 待办事项和日程管理应用。用户反馈：经常想记录「我做了什么」但懒得点待办完成，且晚上十点看 AI 日报时想看到今天实际做了什么、时间花在哪了——不只是计划。本版本新增「实际记录层」，与待办/日程并列，专门回答"我今天到底做了什么"。

**核心诉求**：
- 能随时随地开始正向计时（类似秒表），计完自动存记录；
- 能随手补记（已做完才想起来）；
- 看板上能看「今日做了什么」；
- AI 日报呈现实际记录，不只计划。

**不做**：
- 不接电脑同步（后续）；
- 不做独立 Widget（后续）；
- 不挂待办自动完成（记录完全独立）；
- 不动循环/完成逻辑。

  ```kotlin
  @Entity(
      tableName = "activity_records",
      indices = [
          Index(value = ["state", "createdAtMillis"]),
          Index(value = ["groupId"])
      ]
  )
  data class ActivityRecord(
      @PrimaryKey(autoGenerate = true) val id: Long = 0,
      val title: String,                    // 空字符串 = "未命名记录"
      val groupId: Long? = null,            // 可选分组（复用 TaskGroup）
      val startAtMillis: Long,              // 记录开始时刻
      val accumulatedMillis: Long = 0,      // 已累计跑动毫秒
      val lastResumeAtMillis: Long? = null, // 当前正在跑的起点，null=暂停
      val state: ActivityRecordState,       // RUNNING/PAUSED/FINISHED
      val endAtMillis: Long? = null,        // 结束时刻（finish 时设）
      val source: ActivityRecordSource,     // TIMER/MANUAL
      val notes: String = "",
      val createdAtMillis: Long = System.currentTimeMillis()
  )

  enum class ActivityRecordState { RUNNING, PAUSED, FINISHED }
  enum class ActivityRecordSource { TIMER, MANUAL }
  ```
- **有效用时计算**：
  ```kotlin
  fun ActivityRecord.effectiveDurationMillis(nowMillis: Long = System.currentTimeMillis()): Long {
      val running = if (state == ActivityRecordState.RUNNING && lastResumeAtMillis != null) {
          (nowMillis - lastResumeAtMillis).coerceAtLeast(0)
      } else 0
      return accumulatedMillis + running
  }
  ```

- **同一时刻只允许一条非 FINISHED 记录**（秒表模型）：`startActivityTimer` 前先检查，有活动记录则先 finish 它。
- **finish 时 <5 秒丢弃**：计算有效用时，若 <5000 毫秒则不存库直接删。

#### 2.2 通知设计
```kotlin
private fun buildTimerNotification(record: ActivityRecord, context: Context): Notification {
    val intent = Intent(context, MainActivity::class.java).apply {
        flags = Intent.FLAG_ACTIVITY_NEW_TASK or Intent.FLAG_ACTIVITY_CLEAR_TOP
    }
    val pendingIntent = PendingIntent.getActivity(...)
    
    val pauseOrResumeAction = if (record.state == ActivityRecordState.RUNNING) {
        NotificationCompat.Action(R.drawable.ic_pause, "暂停", pausePendingIntent)
    } else {
        NotificationCompat.Action(R.drawable.ic_play, "继续", resumePendingIntent)
    }
    
    return NotificationCompat.Builder(context, CHANNEL_ID)
        .setSmallIcon(R.drawable.ic_stat_payki_todo)
        .setContentTitle(record.title.ifBlank { "未命名记录" })
        .setContentText("正在记录...")
        .setUsesChronometer(true)
        .setWhen(record.lastResumeAtMillis ?: record.startAtMillis)
        .setOngoing(true)
        .setContentIntent(pendingIntent)
        .addAction(pauseOrResumeAction)
        .addAction(R.drawable.ic_stop, "结束", finishPendingIntent)
        .build()
}
```

#### 5.3 辅助函数
```kotlin
private fun activityLine(record: ActivityRecord): String {
    val duration = record.effectiveDurationMillis() / 60_000
    val start = millisToLocalDateTime(record.startAtMillis)
    val end = record.endAtMillis?.let(::millisToLocalDateTime)
    val timeRange = if (end != null) "${clockTime(start)}-${clockTime(end)}" else clockTime(start)
    return "${record.title.ifBlank { "未命名" }}（$timeRange，${duration}分钟）"
}
```
