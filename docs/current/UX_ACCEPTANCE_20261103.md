## 1. 环境与记录规则

1. 记录实际代码 HEAD、两端版本、实际 EXE/APK 路径和测试资料目录。不要用历史包验收新代码。
2. 使用隔离账号/本地资料；未经保护不操作用户真实库。Windows 用独立 Win32 桌面测试入口，避免抢占用户键鼠；Android 复用既有可用测试设备并遵循备份规则。
3. 日期样例使用可注入时钟或隔离 fixture。不要为了测试改系统时间；过去样例可在数据层测试，UI 到点提醒改用实际未来时刻。
4. Windows 常规窗口覆盖 1280×850 DIP、最小允许窗口和与用户截图相同的物理输出尺寸。DPI 覆盖 100%/125%/150%/200%；字体至少方正小标宋与系统推荐，字号覆盖默认和较大值。不要求所有页面做完整笛卡尔积，优先小字密集的日历/编辑器，问题位置再补全。
5. 手机阅读表面覆盖 320/360/412 CSS px，正常与较大字体，明/暗主题。Web CSS px、Android dp/sp、Windows DIP、截图物理像素须分别记录。
6. 截图保持原始分辨率。放大拼图只能辅助观察，必须保留未经缩放的原图。
7. 每条结果记录“通过/失败/未验证、实际步骤、观察结果、证据路径”；自动化与手工结果分开，重跑不重复计数。
