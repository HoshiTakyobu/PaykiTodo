# 1.16.26 日历复核与 Windows 安装包

本轮从 `1.16.25 / versionCode 390` 开始，核对原有日历和体验反馈，并交付可在 Windows 10 1809+/11 x64 安装的中文 MSI。

- 复核独立日历、创建/取消/保存、日历显隐、字体、设置和倒数日状态。
- 补齐循环操作作用域、跨午夜锚点、全天排他结束、多时段统一提交和日历颜色联动。
- 独立小月历翻月、侧栏滚动、窄窗口重排、拖动改期和结束边缘调整。
- Windows 本机 OCR；Android 完成后的纪念询问即时更新。
- MSI 安装、模拟旧版升级、路径记忆、修复、安装后的实际 EXE 和卸载保留资料验证。
