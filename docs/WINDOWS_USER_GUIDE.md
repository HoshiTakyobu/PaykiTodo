# PaykiTodo Windows 使用说明

## 开始使用

PaykiTodo 把待办、日程、提醒和倒数日放在同一个工作区。Windows 客户端保存自己的本地副本，使用同一账号可与手机同步。

首次打开时选择登录服务器，再注册或登录账号。服务器由服务提供者提供；账号属于所选服务器。不要把“连接手机”中的局域网地址填作账号服务器。

登录成功后，即使网络暂时不可用，也可以继续查看和编辑已有本地数据。同步会在恢复连接后继续。明确退出账号会锁定工作区，但保留本地数据。

打开“设置 → 常规 → 使用说明”，或在主窗口按 F1，可离线阅读这份帮助。

## 每日看板与待办

每日看板展示今日待办、今日日程和近期目标。需要完成但没有固定时段的事情适合建成待办；明确占用一个时间段的安排适合建成日程。

点击“新增待办”，填写标题、可选截止时间、提醒和分组，再点击“完成”。按取消或关闭编辑窗口不会保存草稿。点击待办前的圆形勾选框可标记完成；历史记录中的事项可以恢复。

本版的快速清单可一次输入多条待办并预览层级。清单里的每条任务仍是普通数据库记录，支持完成、历史查看和备份。

## 日历与日程

日历支持日、周、月和列表视图。宽度不足或选择较大字号时，周视图会减少同时显示的天数。点击“今天”返回当前日期，用左右箭头切换当前视图范围。

在时间网格空白处单击可预览一个时段，再次点击蓝色草稿打开编辑器。也可以点击“创建日程”。填写标题、日期和起止时间、地点等，确认后保存。点击已存在的日程查看完整内容。

拖动日程可以改期，拖动下边缘可以调整结束时间；按 Esc 取消拖动。修改循环事项时，请留意“当前、当前及之后、全部”的范围选择。取消编辑不会改变整个系列。

日历与任务分组是两种不同的分类。隐藏一个日历只影响显示，不会关闭其中的提醒。日历设置中可以调整默认时长、提醒、周起始日、颜色样式和显示时区。

## 提醒、历史与倒数日

有截止时间的待办可以在截止前或截止时提醒；日程通常相对开始时间提醒。修改提醒后，先确认时间和开关，再完成编辑。新录入的历史时间不会补响已经过去的提醒。

桌面提醒需要程序保持运行；关机、休眠或退出程序时无法按时弹出。手机的通知、锁屏权限与电池管理由 Android 单独控制。两端使用同一账号，并不意味着电脑退出后仍能代替手机提醒。

已完成或取消的事项进入历史，清理显示不会自动删除你的所有日程和待办。倒数日用于关注目标日期，完成后可以选择保留纪念。常规设置中的历史倒数日天数只影响展示。

## 规划输入与 AI 报告

本版规划台支持写入文本、识别、预览修改、确认导入。确认前检查事项类型、日期、起止时间和提醒，识别结果不会自行成为已确认任务。

本地识别无需 AI API。需要使用 AI 时，在“设置 → AI 与规划 → AI 服务配置”添加兼容的服务地址、密钥和模型，先测试连接。AI 的识别结果同样需要你确认。

AI 报告根据相关待办和日程生成日报或周报。AI 请求会把用于生成的事项数据发送到你配置的服务。服务费用和可用性由服务提供者决定，密钥不包含在正常迁移包中。

## 字体、字号与主题

打开“设置 → 常规 → 选择字体”，可以输入本机字体的中文或英文名称，也可以从列表选择。下拉列表优先显示中文名称；尚未安装的字体不能直接选用。

正文字号可在 12—22 px 之间调整，默认 14 px。滑块旁会显示数值，下方同时预览中英文、数字、任务时间和输入框。只有点击“完成”才应用并保存；取消保留原来的字体和字号。

字号按界面层级调整标题、正文和输入框。品牌、导航图形以及看板问候字样保持原设计。设置会随数据副本保留；另一台电脑没有安装所选字体时使用系统推荐字体。

主题可选择浅色或深色。窄窗口里的设置操作会排到说明下方，内容较多时可向下滚动。

## 备份与同步

“设置 → 数据与备份 → 导出备份”生成 .paykibak 迁移包，可供 Windows 与 Android 导入。重要修改前可以主动导出一份副本。备份文件包含个人事项，应保存在你信任的位置。

从迁移包恢复会替换当前本机数据，程序会先保留操作前副本。请阅读确认信息并核对文件来源。遇到同步分歧时，先检查云端与本机记录，再决定恢复方向；不要反复尝试覆盖。

程序会自动同步，设置中也提供“立即同步”。独立事项的改动可以自动合并；同一事项上的竞争修改、删除与编辑等真正冲突仍需明确处理。

“连接手机”是兼容的浏览器入口：手机开启“连接电脑”后，在浏览器访问手机显示的地址，直接操作手机数据。它与独立 Windows 客户端的账号同步互不替代。

## 安装、更新与快捷键

安装版使用 Windows x64 MSI，便携版必须保留解压后的完整目录，不能只复制 PaykiTodo.exe。卸载程序不会自动删除当前 Windows 用户的数据目录。

本版可在“设置 → 关于”查看版本；安装包和发布说明以项目 GitHub Releases 页面为准。更新前建议备份，安装时关闭正在运行的旧版窗口。Android 的 Debug 与 Release 签名不同，不能直接相互覆盖安装。

F1：打开使用说明。
Ctrl+F：定位搜索框，输入标题、地点或备注后按 Enter 查看结果。
Ctrl+N：新增事项；在日历页新建日程，在其他业务页新建待办。
Esc：取消日历拖动或关闭支持取消的窗口。

如遇问题，请记录版本、操作步骤和看到的提示。不要在公开 issue 中粘贴服务密钥、私有服务器地址或包含个人记录的备份。
