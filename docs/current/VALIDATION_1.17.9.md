# 1.17.9 报告改进验收

本阶段从 `730e3fa` 开始，验证跨 2026-10-31 / 2026-11-01。Android `1.17.9 / versionCode 401`、Windows `1.17.9.0`，Room33不变。整轮七项需求仍未全部完成。

## 已实现

- Android、原生 Windows 使用同一份 `app/src/main/assets/ai/report-system.txt`。报告数据按此前、本期、接下来分段，周期前后各七天，每段最多60条并保留总数。周报统一为周一至周日。
- 保留循环系列、多时段关联、父任务、实际完成时间与跨日签到切片。安排、签到、完成分开表述；不再用完成数加错过数推算完成率。过滤无访问权限的共享日历，不发送账号、服务密钥等配置。
- 关怀措辞必须有记录依据；仅有用药安排时提醒遵照既定医嘱，明确完成后才肯定行动，不能只根据药名推断病情或治疗效果。
- 日报包括本地模板，从生成时间起满604800000毫秒过期，边界包含相等。列表、详情、搜索、读取、导出、导入与合并均排除过期日报；校验备份完整性之后才过滤内容。周报保留配置独立，“永久”不影响日报。
- 手机进程内监测最早到期时间，并登记可跨重启的后台清理任务；Windows启动与主窗口计时器清理本地副本。已经打开的报告详情/列表到期移除。局域网兼容页移除到期摘要，不重绘正在编辑的设置草稿。
- Windows生成报告使用不会随空报告列表回到1的时间型编号。原备份文件保留原样，恢复后不重新导入过期日报。
